# ISP Modeling

Camera ISP modeling adapted from
[simple-camera-pipeline](https://github.com/AbdoKamel/simple-camera-pipeline)
(MIT License; see [LICENSE](LICENSE)). The upstream handles DNG only; this
version adds CR2 support.

The measurement data under [`mat_collections/`](mat_collections/) is
redistributed from the [RSBlur](https://github.com/rimchang/RSBlur) project
under CC BY 4.0; see [`mat_collections/README.md`](mat_collections/README.md).
